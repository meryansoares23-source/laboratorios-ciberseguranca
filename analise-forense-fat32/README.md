
# Análise Forense de Sistemas de Arquivos FAT32

## Objetivo
Estudar a estrutura do sistema de arquivos FAT32 e aplicar conceitos de análise forense digital para identificar e interpretar evidências em dispositivos de armazenamento.

## Laboratório
Prática realizada na plataforma TryHackMe, envolvendo análise da estrutura FAT32 e investigação de metadados de arquivos.

## Conteúdos estudados
- Estrutura do FAT32: Reserved Area, FAT Area e Data Area.
- Boot Sector e informações do sistema de arquivos.
- File Allocation Table (FAT).
- Clusters e cadeias de alocação.
- Entradas LFN (Long File Name) e SFN (Short File Name).
- Análise de metadados e timestamps.
- Identificação de arquivos ocultos e excluídos.
- Análise hexadecimal de estruturas de arquivos.

## Ferramentas utilizadas
- TryHackMe
- HxD Hex Editor

## Aplicação em Cibersegurança
O conhecimento sobre análise de sistemas de arquivos é utilizado em investigações de incidentes, recuperação de arquivos, identificação de evidências digitais e análise de atividades suspeitas em dispositivos de armazenamento.

## Aprendizados
A prática ajudou a compreender como os arquivos são organizados e armazenados no FAT32, como interpretar metadados e como a análise hexadecimal pode auxiliar na investigação forense digital.

## Área de interesse
Digital Forensics and Incident Response (DFIR), Segurança da Informação e Cybersecurity.
